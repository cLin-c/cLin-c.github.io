🔬 研究方向

博士课题聚焦于 具身智能灵巧操作，具体研究：

  • 视觉–触觉多模态感知融合（视触觉对齐、盲抓稳定）
  • 灵巧手精细作业控制（亚毫米级精度，力控闭环）
  • ECRP 多视角环境感知框架（解决视觉遮挡）
  • PECHC 分布式触觉抓握稳定化
  • VLAC 持续学习智能体（5–10 次交互掌握新技能）

应用场景：核设施维护 · 生化实验 · 深海/深空 · 爆炸物处置

核心研究框架

👁️

ECRP

Environment-Centric Multi-Perspective Perception Framework

面向移动操作机器人的以环境为中心的多视角感知框架，有效解决操作过程中的视觉遮挡问题。

IEEE TRO · IF 10.5 · 在投
✋

PECHC

Robust Tactile Grasping Stabilization in Vision-Denied Peripersonal Space

在视觉遮挡近端空间内，利用分布式触觉传感实现鲁棒抓握稳定控制。

IJCAI · CCF-A · 已录用
🤖

VLAC

Vision-Language Actor-Critic Continuous Learning Agent

基于实时 Critic 评估与失败驱动优化的持续学习智能体，5–10 次交互即可掌握新技能。

进行中
🔗

视触觉融合双层架构

ECRP + PECHC Hierarchical Multimodal Sensing

环境侧多视角感知 (ECRP) + 本体侧分布式触觉 (PECHC)，实现亚毫米级精细接触控制底座。
